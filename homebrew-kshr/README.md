# Homebrew Tap for kshr

This is the official Homebrew tap for [kshr](https://github.com/yosefkohan26/kshr), a Ghostty-based macOS terminal with vertical tabs for AI coding agents.

## Installation

```bash
brew tap yosefkohan26/kshr
brew install --cask kshr
```

## Updating

```bash
brew upgrade --cask kshr
```

## Uninstalling

```bash
brew uninstall --cask kshr
brew untap yosefkohan26/kshr
```
